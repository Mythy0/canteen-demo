# 食堂账单可信分析器

> 问一句，它给数字，也给你能核对的每一步。

面向「可信AI挑战赛」（2026.11.21，无锡锡山）的参赛作品。把「AI 算得准、结果有据可查」做成一个能当场演示的小工具。

## 它做什么

粘贴一份食堂消费记录（每行一条：日期 时间 商户 金额），用中文直接问：

- 这学期食堂花了多少 / 10 月花了多少 / 一食堂花了多少
- 哪天花得最多 / 单笔最贵的是哪笔 / 平均每笔多少 / 最常去哪家
- 单笔超过 15 元的 / 一共几笔

每个回答都给同一套东西：**结论、算式、依据清单、数据缺陷说明、逐条明细**。

## 可信体现在哪（四件具体的事）

1. **数字不经过模型。** 金额由本地确定性代码计算，同一份数据任何时候算出来都一样，可以复现。
2. **每一步都摊开。** 算式里列出真实参与计算的金额；「依据」写清时间范围、纳入多少条、包含哪些商户。
3. **交叉校验。** 同一批数据用两种方式求和 —— 逐条相加 vs 按月分组相加 —— 结果不一致就在页面上标红，不静默通过。
4. **主动说不知道。** 超出范围的问题（比如「今天天气怎么样」）不做猜测，直接列出它能回答什么；数据连续 4 天以上没有记录、有行解析失败，都会在结论下方提示，而不是假装完整。

## 为什么把「理解问题」和「算数」分开

一个想法：模型可以理解你在问什么，但账不该让它算。

自然语言理解允许出错，因为错了你看得见（算式对不上）；数字计算不允许出错，所以交给确定性代码。这也是这个 demo 和「直接问 ChatGPT 我的账单」最大的区别 —— 后者你只能信，前者你可以查。

## 运行

- **在线**：<https://mythy0.github.io/canteen-demo/>
- **本地**：下载 `index.html`，用浏览器打开即可。没有构建、没有依赖、不联网。
- 数据只在当前页面内存里计算，不发往任何服务器。

## 数据格式

每行一条，空格分隔：

```
2026-09-02 11:52 一食堂 12.5
```

时间可省略；日期支持 `2026-09-02`、`2026/9/2`。界面里有「示例数据」按钮，一份 2026 年秋季的 52 条账单可以直接试。

## 已知局限

- 不直接解析微信/支付宝导出的账单，需要先整理成上面的格式
- 只把名称含「食堂 / 餐厅 / 美食」的商户算作食堂，其他默认排除
- 问题理解目前是关键词规则，不是模型；问法太绕会落到「答不了」
